# Lambdas and Streams — Code lab

Build a shop's morning reports: load orders from a database table, build rules from lambdas, and turn the list into reports with streams. The last task moves a total into SQL.

- **Edit:** the classes in `src/main/java/exercise/` named in the checklist. Each task is marked `TODO`.
- **Run the tests:** **Run Tests** in Exa Studio, or `mvn test` with JDK 17 and Maven. All 8 visible tests fail at first; every message starts with `Task N:`.
- **Done** when every visible test passes. **Submit** also runs held-out tests you can't see.

Full task steps and hints: [`.evolv/instructions.md`](.evolv/instructions.md)
